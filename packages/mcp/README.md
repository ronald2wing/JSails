# @jsails/mcp

Model Context Protocol for JSails: tools, resources, resource templates, and prompts defined and checked at define time, served over stdio to both protocol eras (2026-07-28 and the 2025 revisions), a client for remote servers over Streamable HTTP or stdio, and an in-process connection for tests.

```sh
npm install @jsails/mcp zod
```

Documentation: <https://jsails.org/docs/mcp>
