# @jsails/editor

The rich-text editor for JSails: a ProseMirror editor (toolbar, insert menu, link dialog, task lists, media blocks) that edits the persisted `jsails/rich-text` document, the Preact form-field island that hydrates rich-text fields, and the server-side HTML renderer and field markup. Install it with `npm install @jsails/editor` and read the guide at <https://jsails.org/docs/editors>.
