# @jsails/inertia

The server half of the Inertia v3 protocol for JSails: prop descriptors (`always`, `optional`, `defer`, `merge`, `once`, `scroll`), partial reloads, the v3 page object, error bags, a strict page serializer, the `<script data-page>` document, the asset version hash, and the outcome layer: the version guard, `409` control responses, redirect rules, the Origin check that is Inertia's CSRF defence, a sealed one-shot cookie for flash and validation errors, Precognition, and SSR gateways (in process with preact-render-to-string, or over HTTP). It works with the official Inertia v3 clients and is tested end to end against `@inertiajs/react` 3.11.0 on `preact/compat` and React 19. `@jsails/inertia/testing` builds the requests a client sends and reads the page and the carrier out of a response. Install it with `npm install @jsails/inertia`; the framework documentation is at <https://jsails.org/docs>.
